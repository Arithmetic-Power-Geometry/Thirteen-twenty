# Non-negotiable novelty / verification gates

## Gate A — Foundational mathematics
- Check analytic lemmas and the finite certificate for q=16 (13/20) without using floating-point feasibility decisions.
- Verify 11,698 primitive-pair count and equality up to gcd scaling and swap.
- Re-run with independent decision logic, not merely a second implementation of the same bug.
- Confirm the statement concerns aligned additive integer frequencies only.

## Gate B — Formal algorithms
- Input encoding, rational representation and exact endpoint conventions stated.
- Total correctness proved: YES witness, NO completeness and termination.
- Complexity in numerical parameter and in bit length; no concealed pseudopolynomial complexity.
- Multi-job results explicitly separate generic NP-hard cases from what holds for the restricted model.

## Gate C — Originality
- Compare specialized periodic scheduling and admission literature, existing interval/data-structure methods, constraint programming and real-time verification.
- Make a novelty matrix: closest result / our assumptions / claim / advantage / proof / artifact.
- Do not assume an elementary corollary of the 13/20 measure or a standard binary search is novel.
- Stop Q1 submission if no nontrivial, independently novel CS theorem or empirically important validated system result exists.

## Gate D — Reproducibility
- Independently validate every figure, table, lemma-dependent experiment and claimed numerical bound.
- Pin package/compiler versions and cryptographic hashes.
- Record raw workloads, outputs, seeds, environment and exact reproducibility commands.
- Never relabel simulation outputs as physical real-time measurements.

## Gate E — Paper integrity
- Natural scholarly prose; no author instructions, internal workflow labels or AI-generation claims in the paper.
- All figure/table/algorithm cross-references cited and consistent.
- References bibliographically verified and meaningfully cited.
- Artifact-provenance statement reflects actual development chronology.
- No promise of Q1 acceptance; journal-specific requirements verified before submission.
