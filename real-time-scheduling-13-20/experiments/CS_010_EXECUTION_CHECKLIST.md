# Reproducibility acceptance checklist

| Gate | Requirement | Current status |
|---|---|---|
| Source availability | Source code and tests committed | YES |
| CI configuration | Python 3.11/3.12 workflow committed | YES |
| Full tests passing | Actual successful run logs inspected | UNVERIFIED |
| Benchmarks complete | JSON from successful run inspected | UNVERIFIED |
| Independent reproduction | Different implementation/environment agrees | UNVERIFIED |
| Fair performance claim | Repeated runs, controls, dispersion | UNVERIFIED |
| Closest-prior-work | Originality comparison with verified sources | UNVERIFIED |
| Q1-level new result | Nontrivial original theorem or verified systems contribution | NOT ESTABLISHED |

No unverified cell may be silently upgraded to PASS in the paper.
